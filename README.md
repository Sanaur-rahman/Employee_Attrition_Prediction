# Employee Attrition Prediction

Predicting whether an employee will leave the company or not, using Logistic Regression.

## Results

| Model | Accuracy | Precision |
| :--- | :--- | :--- |
| Baseline | 85.92% | 87.17% |
| L1 Regularization (Lasso) | 87.77% | 87.09% |
| L2 Regularization (Ridge) | 85.92% | 87.17% |

**Winner: L1 Regularization**
L1 removes useless features and makes the model simpler. It improved accuracy from 85.92% to 87.77%.
